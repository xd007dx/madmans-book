## 1. 修正実施における絶対原則

本計画は、過去に発生した「AIによる自己判断での一括改変」「退行の多発」「虚偽の完成報告」を恒久的に防ぐため、以下の鉄則を厳格に遵守して実行する。

1. **コードの一括変更・複数同時修正の絶対禁止**:
   1つのステップでは必ず「1つの機能」または「1つのバグ」のみを対象とし、変更箇所を最小限に抑える。
2. **修正前の「第1段階〜第3段階」確認**:
   対象箇所の周囲コード、実行経路、上書きリスクを事前に100%把握してからパッチスクリプトを作成する。
3. **パッチスクリプトの「アサーション（存在確認）」必須化**:
   `QueueFindReplace` の前に、必ず対象文字列がコード内に存在することをC#側で検証し、存在しない場合はスクリプトを即時エラー停止（例外送出）させる。
4. **「SUCCESS」表示を信用しない**:
   スクリプト終了後、必ず対象コードを逆コンパイルしてテキスト照合を行い、期待通りのコードへ変化したことを確認する。
5. **実機テストの完了確認**:
   逆コンパイル確認後、必ず `wifes_bedroom.exe` を起動し、`HARDWARE_TEST_PLAN.md` に基づく操作を行って挙動を目視確認する。
6. **3回失敗時の停止ルール**:
   同一ステップで3回パッチや動作に失敗した場合は、直ちに作業を中断し、前提条件やバイナリ構造の再調査に戻る。

### 【Phase 0】 パッチ環境・検証フレームワークの健全化
**目的**: 「サイレント空振り（0件置換成功）」を防ぐ安全なパッチ実行環境を構築する。

* **Step 0.1: 安全なCSXテンプレートの策定**
  - UTMTスクリプト内で置換対象コードの存在確認（`code.DecompileToString().Contains(target)`）を行い、未検出時は `ScriptError` で中断するラッパー関数を定義する。
* **Step 0.2: 逆コンパイル比較ルーチンの自動化**
  - パッチ適用前後のコード差分を自動出力し、目的以外のコードが変化していないことを検証できる体制を整える。

### 【Phase 1】 致命的バグ・超インフレの是正（安全性の確立）
**目的**: ゲームバランスを崩壊させている数値異常や進行不能バグを最優先で是正する。

* **Step 1.1: ID 30 (777フィーバー) 毎フレーム加算バグの修正**
  - **対象**: `gml_Object_oFutaMatingPress_Step_0.gml`
  - **内容**:
    - `Step_0` 390-393行の毎フレーム `futa_score += 777/7777` を削除。
    - `Step_0` 61行の「絶頂突入瞬間（`sex_progress >= sex_progress_max`）」のブロック内に、1回のみ加算する処理を移設。
  - **検証**: TEST-004 を実機で実行し、1射精で +777 (OD時 +7777) のみ加算されることを確認。

* **Step 1.2: コンドーム未射精抜去バグの修正**
  - **対象**: `gml_Object_oFutaMatingPress_Draw_0.gml`
  - **内容**:
    - Line 716 の `condom_size = min(3, stat_liters / 5);` を修正。
    - 抜去判定（Line 725, Line 598）において、`current_condom_has_cum == false` の場合は `condom_size = 0` とし、精液コンドームのインスタンス生成をスキップして空のゴムとして破棄する。
    - 抜去完了時に `current_condom_has_cum = false;` を確実にセットする。
  - **検証**: TEST-003 を実機で実行し、大量射精実績後に新品ゴムを即抜去しても空のまま外れることを確認。

* **Step 1.3: Create_0 の `custom_condom` 二重代入バグの修正**
  - **対象**: `gml_Object_oFutaMatingPress_Create_0.gml`
  - **内容**:
    - Line 394 の `custom_condom = sFutaCondomBrokenNormal;` を `custom_condom_broken = sFutaCondomBrokenNormal;` に修正。
  - **検証**: カスタムキャラ読み込み時に通常コンドーム画像が破損しないことを確認。
