### 【TEST-001】 無限アンコールガズム 連続発動実機テスト

* **検証目的**: アンコールガズムが1回制限ではなく、射精終了寸前にお尻を叩くことで何度でも連続して全回復するかを検証する。
* **前提条件**:
  - キャラクターは何でも可。コンドームは外した状態（生）。
  - ピル: 特別なピルは不要（初期状態）。
* **操作手順**:
  1. ゲームを開始し、挿入状態にする。
  2. マウスを上下に動かしてピストンするか、またはキーボードの `M` キーを押して強制絶頂させる。
  3. 射精が開始され、画面中央または右上の射精ポンプ数（`orgasm_pumps`）が減少し始めるのを目視する。
  4. 射精ゲージが残り少なく（`orgasm_pumps < 3` または `< 5`）なった瞬間に、妻のお尻をクリックして強烈にスパンキングする。
  5. 「ENCORGASM」の文字が表示され、射精ポンプが最大値まで全回復することを確認する（1回目）。
  6. その後、何もしないで射精を継続させ、再度ポンプ数が減ってきたタイミングでもう一度お尻をクリックしてスパンキングする。
* **期待挙動 (PASS条件)**:
  - 1回目のスパンキングでアンコールが発動し、射精が全回復すること。
  - **同一の射精中において、2回目のスパンキングでも再度「ENCORGASM」が発動し、射精が再び全回復すること**。
  - 叩き続ける限り、射精が切れずにエンドレスに行為が継続すること。
* **異常挙動 (FAIL条件)**:
  - 1回目は回復するが、2回目以降にお尻を叩いても「ENCORGASM」が表示されず、そのまま射精が終了して疲労セリフに移行する（REG-001退行状態）。

### 【TEST-003】 コンドーム未射精抜去 10ケース完全検証テスト

* **検証目的**: 過去に射精した実績がある状態で、新品コンドームを装着して未射精のまま抜いた際、精液満タンのコンドームが誤生成されないかを検証する。
* **前提条件**:
  - コンドームを装着可能な状態。
* **操作手順**:
  1. **【ケース1: 累積射精の蓄積】**: コンドームを外した生挿入状態で数回射精させ、`stat_liters` を 5.0L 以上に蓄積させる。
  2. **【ケース2: 新品コンドーム装着】**: メニューからコンドームを装着する。
  3. **【ケース3: 射精前の即抜去】**: ピストンを1〜2回だけ行い、**絶対に射精させずに** ペニスをクリックしてコンドームを取り外す。
  4. 床にドロップしたコンドームオブジェクト（または取り外し時のエフェクト）を目視確認する。
* **期待挙動 (PASS条件)**:
  - 過去にいくら射精していても、**今回のゴム内で射精していないため、コンドームは膨らまずサイズ 0 の空の状態で破棄される（または中身なしの萎んだゴムとしてドロップする）**。
  - 精液水音（sndSlosh）が鳴らず、ボーナススコア「FILLED CONDOM」が加算されないこと。
* **異常挙動 (FAIL条件)**:
  - 未射精で抜いた瞬間に、「バシャッ」と大量の精液音とともにパンパンに膨らんだ特大コンドームが床に落ちる（現行BUG-001状態）。

### 【TEST-004】 ID 30 (777フィーバー) 絶頂時スコア加算テスト

* **検証目的**: ID 30 のスコア加算が「絶頂突入時に1回のみ」実行され、毎フレーム連続加算によるインフレが発生しないかを検証する。
* **前提条件**:
  - ピル: ID 30 (Casino Lucky) 単体、および ID 30 ＋ ID 19 (Overdose) 併用。

  2. 画面右上の現在のスコア（`futa_score`）の数値をメモする（例: 0 pt）。
