## [v4.1] - 2026-09-03 (Perfect Refined Edition)

### 🌟 ピル仕様変更 ＆ バランス整流
- **多重連鎖絶頂 (Time Delay: ID 31) ➔ マシンガン射精へ仕様刷新**:
  - タイマー延長（引き抜けなくなるフリーズバグ）を撤廃。
  - 射精ポンプのインターバルを大幅短縮（`orgasm_timer -= 2` / OD時 `-3`）し、怒涛の超高速連射射精（マシンガン射精）へと進化。
- **777フィーバー (Casino Lucky: ID 30) 100%確定化 ＆ OD時 7,777ボーナス**:
  - 確率抽選を撤廃し、絶頂時に **100%確定で $+777$** 加算。OD併用時は **$+7,777$** の特大フィーバーボーナス。
- **メガ精子 (Mega Sperm: ID 1) × OD の玉サイズスマート化**:
  - 視覚的な玉サイズ肥大を最大 `1.4倍` に抑制。画面の邪魔にならず、内部の射精量・精子数を大幅ブースト。
- **極限寸止め (Edge Meister: ID 23) × OD シナジー実装**:
  - OD併用時は1回の寸止めで即座に上限 `10倍（感度1000%）` に到達。
- **先走り漏出（ID 9）vs 極限先走り漏出（ID 35）の OD 差別化**:
  - 先走り漏出（ID 9）× OD: 確率2倍（通常 $2/11$、スパンキング $100\%$ 確定）。
  - 極限先走りEX（ID 35）× OD: $100\%$ 確定漏出 ＆ 漏出量2倍。
- **妻の絶頂ペース正常化**:
  - 官能覚醒（ID 34）の快感度毎フレーム加算を撤廃（あえぎ声確率95%〜100%に特化）。
  - 常時絶頂状態を解消し、自然なプレイスピードへ整流。

### 🔧 不具合修正 ＆ UI・フォント改善
- **スパンキング（`slap_boost`）によるピストン急加速の完全復旧**:
  - `Step_0.gml` の代入ガードを整流し、お尻スパンキング時の `thrust_speed = 10〜16` 一時加速を正常連動。
- **未射精時の抜去コンドームサイズ誤判定バグの修正**:
  - 過去の通算射精量ではなく「今回のコンドームでの実射精フラグ（`current_condom_has_cum`）」を判定し、未射精抜去時は `condom_size = 0` を維持。
- **奇跡の多胎繁殖（ID 32）受精アニメーションフリーズ修正**:
  - 受精開始時の配列初期化とタイマー遷移を修復。
- **言語切り替え・フォント動的スイッチ ＆ UIクローズ修正**:
  - 英語選択時は原作のピクセル風フォント、日本語選択時は動的日本語フォントに自動切り替え。
  - 言語選択後にメニューが自動で閉じるよう `submenu = -1` を追加。
- **UIクリック透過（奥のドラッグ・ペニス掴み誤作動）の防止**:
  - メニュー展開時は `penis_grab = false` とし、UIクリックが背後の操作に透過しないようガード。

### 💡 カスタムテンプレート整備
- `custom/_TEMPLATE_LOVER/` および `_TEMPLATE_PARTNER/` に `moan_slow/`, `moan_fast/`, `orgasm/` フォルダと配置ガイドを新設。
- テンプレートの `custom_data.futa` / `custom_data.spouse` における `condom_y = 78` 等の座標ズレを修正。
