# Wife's Bedroom - コンドーム力学・破裂 ＆ ドロップ物理仕様書 (v4.0 決定版)
# (05_CONDOM_MECHANICS_AND_DYNAMICS.md)

本仕様書は、コンドームの装着・伸張・精液充填膨張式、破裂判定力学、床落下（ドロップ）時の物理挙動、ピルとの相互作用、および**「未射精時の抜去サイズ誤判定バグ」の原因と対策仕様**を詳細に定義します。

---

## 1. コンドームの精液充填 ＆ 膨張力学式 [✅ 実装確認済]

射精時、精液がコンドーム先端に注ぎ込まれることで、リアルタイムにゴム風船（バルーン）が膨張します。

### ① 膨張計算方程式 (v4.0 解放仕様)
$$\text{condom\_size} = \min\left( \text{cap}, \frac{\text{stat\_liters}}{2.5} + 0.1 \right)$$

* **通常時のサイズ上限 (`cap`)**: **`6.0倍`**（v3.0の3.0倍制限から大幅拡張）
* **無限子宮（ID 24）有効時**: **`10.0倍`**
* **無限子宮（ID 24）＋ オーバードーズ（ID 19）併用時**: **`20.0倍`**（画面全体を覆う超特大バルーンへ到達）

### ② コンドーム弾性振動 (`condom_jiggle`)
* 射精ポンプ作動時: `condom_jiggle = 0.1` が加算され、ドクドクと脈打つ弾性アニメーションを描画。
* ターボ・ドライブ（ID 20）時: 高速ピストン摩擦により小刻みに振動。

## 2. コンドーム耐久度 ＆ 破裂（Burst）力学 [✅ 実装確認済]

コンドームには耐久値および破裂判定が存在し、激しい性行為や特定のピルによって挙動が変化します。

### ① 耐久度と破裂確率
* **通常時**:
  - 耐久度: `condom_break = 20`（約20%の確率で破裂判定）
  - 耐久度表示: $\text{Durability} = 100 \times (1 - \frac{1}{\text{condom\_break}})\%$
* **重装甲ラバー（ID 36）/ スタミナ（ID 8）有効時**:
  - 耐久度: `condom_break = 999999`（破裂率 1/999999、ほぼ絶対破れない）
* **オーバードーズ（ID 19）併用時**:
  - **`condom_breaking_override = true`** が発動し、どんな激しいピストンや大容量精液でも**破裂を100%完全防御（絶対無敵）**。

### ② 百発百中受精（ID 26）による強制破裂
* **挙動**: 百発百中受精ピルがアクティブな状態でコンドームを装着して射精した場合、絶頂の瞬間にゴムが耐え切れず爆発破裂（`condom_broken = true`, スプラッシュ飛散）。
* **結果**: 避妊を強制突破し、100%生中出し受精へ移行します。

## 3. 床ドロップ（落下）物理 ＆ コレクション [✅ 実装確認済]

射精後、ペニスからコンドームを取り外すと、使用済みコンドームオブジェクト（`oCondom`）としてベッドや床へドロップします。

* **サイズ維持ドロップ (v4.0 改善仕様)**:
  - 旧仕様（v3.0以前）では床ドロップ時に `condom_size / 2` でサイズが半減されていましたが、v4.0では**実サイズ（最大6.0倍〜20.0倍）を完全維持したままドロップ**します。
* **物理挙動**:
  - `instance_create_depth` により生成され、重力・バウンド物理で床へ着地。
  - マウスドラッグで掴んで移動・投擲が可能。
  - 精液色（`cum_color`）とコンドーム色（`condom_color`）がブレンドされた半透明テクスチャで描画。

## 4. 【不具合分析 ＆ 対策仕様】未射精時の抜去サイズ誤判定バグ

### ① 症状
「射精後にペニスを抜いてコンドームを装着し、挿入後すぐに射精せず抜くと、なぜかコンドームに精液が溜まっているように膨らんでしまう。」

### ② コード上の根本原因 (Root Cause)
`Draw_0.gml` (Line 708〜714) の抜去処理において：

```gml
if (condom == true)
{
    // ❌ 過去の通算射精量 (stat_liters) を無条件に参照して計算している
    condom_size = min(..., stat_liters / 2.5);
    fill_amount = 0;
    womb_size = 1;
    womb_size_lerp = 1;
}
```

* `stat_liters` は「今回のコンドーム内での射精量」ではなく、**「ゲーム開始からの累積総射精量」**を保持する統計変数です。
* そのため、過去に射精した実績がある状態で新しいコンドームを装着して抜くと、コンドーム内で一度も射精していないにもかかわらず、過去の `stat_liters` に基づいて `condom_size` が再計算されてしまっていました。

### ③ 解決仕様（推奨設計）
「現在のコンドーム内に射精が行われたフラグ（例: `current_condom_loads > 0` または `condom_semen_liters`）」を導入し、未射精で抜いた場合は `condom_size = 0` のまま空のコンドームとして維持するよう整流します。
