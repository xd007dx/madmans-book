# Wife's Bedroom - セーブシステム ＆ データ構造仕様書 (v4.0)
# (09_SAVE_SYSTEM_AND_DATA_STRUCTURE.md)

本仕様書は、ゲームのセーブデータ構造、自動セーブ、および全41種ピルのアンロック状態の永続化仕様を定義します。

---

## 1. セーブ ＆ ロード
- `func_save_game()` により、スコア、累計射精数、アンロック済みピルリスト、カスタム設定が自動保存されます。

---

## 2. ピルアンロックシステム
- ゲーム進行またはピル獲得に伴い、リスト（`pill_effects_unlocked`）にIDが追加され、メニューからいつでも選択可能になります（v4.0ではID 0〜40の全41種が完全開放可能）。
