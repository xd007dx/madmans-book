# Wife's Bedroom - マスター仕様書 v4.0 (決定版)
# (00_MASTER_SPECIFICATION_V4.0.md)

本仕様書は、GameMaker Studio製ゲーム『Wife's Bedroom』に対する全拡張MOD（全41種ピル、オーバードーズ触媒シナジー、コンドーム力学、UI刷新、成長亜種メカニズム、身体相互作用、日本語ローカライズ）の完全統合マスター設計仕様書です。

---

## 1. 総合アーキテクチャ ＆ システム概要 [✅ 実装確認済]

- **エンジン**: GameMaker Studio (GML Bytecode / UndertaleModTool パッチビルド)
- **対象バイナリ**: `wifes_bedroom.exe` (`data.win`)
- **最大ピル種別数**: **全41種**（バニラ元祖18種 ＋ MOD新規追加23種）
- **UIピル選択グリッド**: 14個×3列（最大42スロット対応レイアウト）
- **UIレーティング体系**: 10段階拡張スケール（最大3.0倍ボディサイズ対応、白/金/ネオンピンクの3段階発光カラー）
- **フォントエンジン**: 日本語動的フォント置換システム（`font_add` による高精細描画、237行完全翻訳）

## 3. オーバードーズ（ID 19）併用時のシナジー規則 [✅ 実装確認済]

- **リアルタイム下限保証**: どの順番でピルを服用しても、ODがアクティブな限り各ピルの最大覚醒倍率（2.5〜2.8x、速度55、充填+40など）が毎フレーム担保されます。
- **排他的優先順位**: 「百発百中受精（ID 26）」のゴム爆発破裂は、「重装甲ラバー（ID 36）」の絶対破壊耐性をも上書きして強制破裂する最優先仕様です。

## 4. コンドーム力学 ＆ バルーンサイズ仕様 [✅ 実装確認済]

- **サイズ拡張上限**: 容量に応じて通常6.0倍、無限子宮（ID 24）時は最大 **10.0〜20.0倍** まで画面いっぱいに巨大化。
- **ドロップ物理**: 使用済みコンドームドロップ（`oCondom`）は、縮小補正なしの完全なバルーンサイズを保持して床へバウンドします。
- **バニラピルのコンドームシナジー**: 原作ピル（ID 0〜17）には固有シナジーは存在せず、標準のコンドーム挙動が適用されます（※将来追加予定）。
